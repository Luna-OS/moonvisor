Moonvisor aktualisiert sich ab jetzt selbst, und Spiele laufen ruhiger.

### Neu
- **Automatische Updates.** Moonvisor sucht beim Start und alle sechs Stunden auf GitHub nach einer neuen Version, lädt sie (etwa 2 MB), prüft sie gegen die Prüfsumme und installiert sie beim Beenden. Mit „Jetzt neu starten“ im Kontrollcenter geht es sofort. Laufende VMs laufen dabei weiter, die neue Version verbindet sich wieder mit ihnen. Abschalten lässt sich das in den Einstellungen unter „Updates“; „Nach Updates suchen …“ steht im Moonvisor-Menü.

### Schneller beim Spielen
- **QEMU läuft mit hoher Priorität.** macOS legt die Prozessoren der VM damit auf die Leistungskerne statt auf die Effizienzkerne. Windows wartet bei jedem Bild auf alle Kerne, ein langsamer Kern ließ Spiele ruckeln.
- **Kein App Nap mehr, solange VMs laufen.** macOS hat Bild und Eingaben gedrosselt, wenn das Moonvisor-Fenster kurz im Hintergrund lag.
- **Profil „Nur Spiele“** schlägt so viele Prozessoren vor, wie der Mac Leistungskerne hat (vorher alle Kerne bis auf zwei, also auch Effizienzkerne). Die Konfiguration weist darauf hin, wenn eine VM mehr Kerne hat.
- **Hinweis zur Grafik:** Für Spiele „DirectX 11 (experimentell)“ wählen. Ohne 3D-Treiber berechnet Windows die Grafik mit dem Prozessor, Spiele laufen dann sehr langsam.

### Aktualisieren
Diese Version einmal von Hand installieren: Moonvisor mit ⌘Q beenden, `Moonvisor-0.2.19-arm64.dmg` laden und die alte App in *Programme* ersetzen. Danach kommen Updates von selbst.
