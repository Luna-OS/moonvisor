Die bisher größte Moonvisor-Version: eigene Engine ohne Homebrew, DirectX 11 (experimentell) und viele Grenzen weniger.

### Neu
- **Keine Installation über das Terminal mehr.** Moonvisor lädt seine Virtualisierungs-Engine (QEMU, TPM, UEFI-Firmware, 3D-Bausteine) beim ersten Start selbst herunter, mit Fortschrittsanzeige und Prüfsumme. Homebrew wird nicht mehr gebraucht.
- **DirectX 11 (experimentell).** Neuer Grafikmodus unter *Konfiguration → Hardware → Grafik*. Moonvisor lädt den Treiber Triton und richtet ihn über die Moonvisor Tools in Windows ein; Windows startet dafür zwei- bis dreimal neu. Das Bild kommt über Metal direkt ins VM-Fenster. Triton ist noch jung: nicht jedes Spiel läuft, DirectX 9 und 12 nicht.
- **Auflösung exakt passend zum Fenster** statt fester Stufen (ab 1024×768).
- **Zwischenablage für Text, Bilder und Dateien** in beide Richtungen (Dateien bis 256 MB).
- **Drag & Drop:** Dateien und Ordner auf das VM-Fenster ziehen, sie landen auf dem Windows-Schreibtisch.
- **Netzwerk mit eigener IP-Adresse** (vom Mac direkt erreichbar, ohne Portweiterleitung) oder als **Bridge** ins lokale Netz. macOS fragt beim Einrichten einmal nach dem Administrator-Passwort.
- **Schnappschüsse merken sich ihre Hardware.** Wer nach einem Schnappschuss CPU, RAM, Grafik oder Ton ändert, kann ihn trotzdem wiederherstellen.
- `moonctl engine install` lädt die Engine auch im Terminal.

### Aktualisieren
Neue `Moonvisor-0.2.0-arm64.dmg` laden und die alte App in *Programme* ersetzen. Bestehende VMs bleiben unverändert.

Für Dateien, Bilder, die freie Auflösung und DirectX brauchen bestehende Windows-VMs einmal die neuen Moonvisor Tools: in Windows die CD „MOONTOOLS“ öffnen und **Moonvisor Tools installieren** ausführen. Danach aktualisieren sich die Tools selbst.

### Bekannte Grenzen
- Kein Mikrofon (die CoreAudio-Anbindung von QEMU kann keine Aufnahme) und kein Coherence-Modus.
- Drag & Drop geht vom Mac in die VM; von Windows zum Mac über die Zwischenablage.
- Moonvisor ist (noch) nicht von Apple notarisiert: beim ersten Start **Rechtsklick → Öffnen**.
