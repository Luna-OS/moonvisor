Keine hängende VM mehr beim Öffnen von Store, Xbox-App und Spielen im DirectX-Modus.

### Behoben
- **VM hing, Protokoll wuchs auf viele MB („poll(2) failed due to: Invalid argument“).** Mit DirectX öffnen Microsoft Store, Xbox-App und Spiele viele Grafik-Verbindungen gleichzeitig. macOS gibt Programmen, die eine App startet, nur ein kleines Limit für offene Dateien. Wurde es überschritten, lehnte macOS jede Abfrage von QEMU ab. QEMU drehte dann in einer Schleife, schrieb bei jedem Durchlauf eine Warnung ins Protokoll, und die VM stand still. Moonvisor hebt das Limit jetzt vor dem Start der VM an.

### Neu
- **Diagnose:** `start.log` notiert das Limit und alle 30 Sekunden, wenn QEMU deutlich mehr Dateien offen hat als zuvor. „Aktionen → Diagnose kopieren“ enthält diese Zeilen.

### Aktualisieren
Ab Moonvisor 0.2.19 kommt dieses Update von selbst, oder sofort über den Update-Knopf im Kontrollcenter und „Jetzt neu starten“. Eine hängende VM einmal ausschalten und neu starten; erst der neue Start bekommt das höhere Limit.
