### Behoben
- **Neue VMs brachen sofort ab mit „cfi.pflash01 device … requires 67108864 bytes, pflash1 block backend provides 329216 bytes“.** Die Moonvisor-Engine (QEMU 10) liefert die Vorlage für die UEFI-Variablen in verkürzter Form, QEMU verlangt sie aber genauso groß wie die Firmware (64 MB). Moonvisor vergrößert die Variablen jetzt beim Anlegen und repariert beim Start VMs, die schon mit der kurzen Vorlage angelegt wurden. Eine gerade neu angelegte VM einfach noch einmal starten.
