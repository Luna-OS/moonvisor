Auflösung frei wählbar und klarere Anzeige, ob DirectX in Windows aktiv ist.

### Neu
- **Auflösung wählen:** In der Werkzeugleiste des VM-Fensters gibt es das Menü **Auflösung**. „An Fenster anpassen“ wie bisher oder eine feste Auflösung von 1280 × 800 bis 3840 × 2160. Die Wahl bleibt pro VM gespeichert. Braucht die Moonvisor Tools in Windows.
- **DirectX-Status im VM-Fenster:** Im DirectX-Modus zeigt Moonvisor an, wenn Windows noch den einfachen Grafiktreiber nutzt (Spiele melden dann z. B. „A D3D11-compatible GPU is required“), und warum. Der Knopf **DirectX-Treiber einrichten** startet die Einrichtung jederzeit von Hand.

### Verbessert
- Schlägt die automatische Einrichtung von DirectX fehl, versucht Moonvisor es nicht bei jedem Start erneut (höchstens zweimal), damit Windows nicht ständig neu startet.
