Behebt den Absturz im DirectX-Modus („Assertion failed: (isv), function hvf_vcpu_exec“).

### Behoben
- **Absturz mit Code 6, sobald der DirectX-Treiber in Windows lief.** Triton blendet Grafikspeicher in 4-KB-Schritten in Windows ein. Der Mac-Hypervisor arbeitete aber mit 16-KB-Seiten, verwarf diese Bereiche („not aligned to page size“), und QEMU brach beim nächsten Zugriff ab. Im DirectX-Modus startet Moonvisor den Hypervisor jetzt wie UTM mit 4-KB-Seiten.
