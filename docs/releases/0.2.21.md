DirectX gleich beim Erstellen einer VM einrichten.

### Neu
- **DirectX 11 im Assistenten.** Beim Erstellen einer Windows-VM gibt es jetzt den Schalter „DirectX 11 für Spiele einrichten“; mit dem Profil „Nur Spiele“ ist er schon an. Die Moonvisor Tools richten den 3D-Treiber (Triton) dann beim ersten Anmelden direkt ein, statt erst den einfachen Grafiktreiber. Windows startet danach einmal neu und meldet sich von selbst wieder an.
  Bisher musste man DirectX nachträglich einschalten. Dann entfernt Windows erst den einfachen Treiber über zwei bis drei Neustarts, und dabei konnte die VM durcheinanderkommen.
- **Moonvisor Tools.** Der Assistent zeigt jetzt an, dass Moonvisor Tools und Treiber (Netzwerk, Auflösung, Zwischenablage, Dateien) automatisch eingerichtet werden.
- **Update-Knopf im Kontrollcenter.** Oben rechts sucht Moonvisor auf Knopfdruck nach einer neuen Version. Updates kommen weiterhin auch von selbst und werden beim Beenden installiert.
- `moonctl create-windows --directx` legt eine VM mit DirectX an.

### Aktualisieren
Ab Moonvisor 0.2.19 kommt dieses Update von selbst (oder sofort über „Jetzt neu starten“ im Kontrollcenter). Ältere Versionen: Moonvisor mit ⌘Q beenden, `Moonvisor-0.2.21-arm64.dmg` laden und die App in *Programme* ersetzen.
