Ein Absturz im DirectX-Modus reißt nicht mehr die ganze VM mit.

### Behoben
- **„Assertion failed: (isv), function hvf_vcpu_exec“ beendete die VM.** Wenn der DirectX-Treiber in Windows auf Grafikspeicher zugreift, den der Mac nicht bereitstellen konnte (etwa weil ein Spiel eine DirectX-Funktion nutzt, die DXMT nicht kennt), brach QEMU bisher sofort ab. Die neue Engine 2 führt solche Zugriffe selbst aus: Lesen liefert Nullen, Schreiben wird verworfen. Schlimmstenfalls stürzt jetzt nur das Spiel ab, Windows läuft weiter.

### Gut zu wissen
- Moonvisor lädt dafür beim ersten Start einmalig die neue Engine (etwa 100 MB).
- Spiele, die DirectX 12 brauchen, laufen mit DXMT weiterhin nicht. Apples D3DMetal, das DirectX 12 könnte, darf Moonvisor nicht selbst verteilen.
