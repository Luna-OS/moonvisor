Behebt den Start im DirectX-Modus.

### Behoben
- **VMs im Grafikmodus „DirectX 11“ starteten nicht** („The console requires a GL context“). Im DirectX-Modus kommt das Bild über SPICE; Moonvisor hat zusätzlich VNC gestartet, das QEMU bei 3D-Grafik ablehnt. VNC entfällt in diesem Modus jetzt.
- Das VM-Fenster verbindet sich im DirectX-Modus direkt mit dem SPICE-Bildschirm, ohne Umweg über VNC.
